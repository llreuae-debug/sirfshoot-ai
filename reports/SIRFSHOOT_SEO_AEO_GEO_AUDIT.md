## 2. Technical SEO Architecture

### 2.1 Dynamic XML Sitemap (`/sitemap.xml`)
The sitemap is dynamically generated by Next.js App Router via `src/app/sitemap.ts`. It includes all 27+ public-facing landing and tool pages with proper change frequencies and search priorities:
- **Core Landing (`/`)**: Priority 1.0, Change Frequency: `daily`
- **Creation Studio (`/create`)**: Priority 0.9, Change Frequency: `daily`
- **Pricing & Plans (`/pricing`)**: Priority 0.9, Change Frequency: `weekly`
- **Free Micro-Tools (`/tools/*`)**: Priority 0.8, Change Frequency: `weekly`
- **Academy & Educational Playbooks (`/cursos`, `/blog`, `/demo`)**: Priority 0.7, Change Frequency: `weekly`

### 2.2 Robots Directives (`/robots.txt`)
Configured via `src/app/robots.ts` with explicit rules:
- **General Web Crawlers (`*`)**:
  - Allowed: `/`, `/create`, `/pricing`, `/tools`, `/blog`, `/demo`, `/cursos`, `/imagens`, etc.
  - Disallowed: `/admin`, `/admin/*`, `/dashboard`, `/dashboard/*`, `/project`, `/project/*`, `/api`, `/api/*`, `/settings`.
- **Generative AI Crawlers (`GPTBot`, `ClaudeBot`, `PerplexityBot`)**:
  - Granted explicit permission to index public educational guides, tools, and `/llms.txt`.
  - Strictly blocked from private creator workspaces and administrative endpoints.

### 2.3 Canonical URLs & Metadata System
Every page inherits from `src/app/layout.tsx` with:
- Standardized `metadataBase`: `new URL('https://sirfshoot-ai.vercel.app')`
- Dynamic Open Graph tags: `og:title`, `og:description`, `og:site_name`, `og:locale: en_PK`
- Twitter card metadata: `summary_large_image`
- Viewport and charset standards.

## 3. Answer Engine Optimization (AEO)

Answer engines (such as Google AI Overviews, Perplexity, and Bing Copilot) prioritize content structured with concise, direct definitions followed by supporting evidence.

3. **Structured Q&A Sections:**
   - Clear FAQ schema and headings with semantic HTML (`<h2>`, `<h3>`, `<p>`).

## 4. Generative Engine Optimization (GEO)

To maximize accurate discovery and citation across Large Language Models, SirfShoot AI implements two dedicated machine-readable endpoints:

### 4.1 Factual Knowledge Base (`/public/llms.txt`)
Following the emerging `llms.txt` standard for AI agents, this file outlines:
- Product identity, official URL, and primary audience.
- Complete breakdown of all 9 agents: Research, Script Engine, Fact Check, Legal Safety, Tone Cloner, Storyboard Director, Thumbnail Designer, SEO Metadata, and Shorts Repurposer.
- Real subscription pricing in PKR (Free Trial: PKR 0, Starter: PKR 499, Creator: PKR 999, Pro: PKR 1,999).
- Contact and support channels.

### 4.2 Machine-Readable Agent Context (`/api/geo-context`)
A dedicated REST endpoint (`GET /api/geo-context`) returning structured JSON with verified features, language support (`en`, `ur`, `roman_urdu`), pricing tiers, and contact metadata for autonomous web agents.

## 6. Core Web Vitals & Performance

Performance optimizations verified during Next.js production build:
- **LCP (Largest Contentful Paint):** Target ≤ 2.5s. Optimized with zero heavy external fonts, vector SVG thumbnails, and font preload.
- **INP (Interaction to Next Paint):** Target ≤ 200ms. Synchronous expensive work avoided; state hydration decoupled via microtasks.
- **CLS (Cumulative Layout Shift):** Target ≤ 0.1. Explicit aspect ratios on containers, video players, and image placeholders.
- **Static Generation:** 50 out of 50 routes prerendered to static HTML and partial prerendering streams.
